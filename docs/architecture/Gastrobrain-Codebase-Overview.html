Gastrobrain — Codebase Overview

Flutter · SQLite · Provider · Material 3 · EN/PT-BR
Flutter SQLite (sqflite) Provider pattern DAO architecture Bilingual EN/PT-BR 2047+ unit tests 73+ E2E tests

Gastrobrain is a comprehensive meal planning and recipe management application. It provides intelligent recipe recommendations, bilingual support, and sophisticated meal planning with multi-recipe meal support. Local SQLite storage with a pluggable recommendation engine and temporal intelligence.

★ Recommendation Engine
Scoring Factors
  • FrequencyFactor
    35% Prioritizes recipes based on desired frequency
  • ProteinRotationFactor
    30% Encourages protein variety with graduated penalties
  • RatingFactor
    10% Considers user ratings
  • VarietyEncouragementFactor
    10% Promotes less-cooked recipes
  • DifficultyFactor
    10% Favors simpler recipes on weekdays
  • RandomizationFactor
    5% Adds variety to results
  • RecipeProximityFactor
    ctx Proximity-based avoidance for recently planned/cooked
  • MealRoleFactor
    ctx Main dish vs side dish suitability awareness
  • UserFeedbackFactor
    dyn Learns from user responses to suggestions

ctx = contextual (no fixed weight) · dyn = dynamic (learned weight) · Temporal: weekday profile emphasises simplicity; weekend profile allows complexity

◉ Development Standards
Form Field Keys — Pattern: {screen}_{field}_field
TextFormField(
  key: const Key('add_recipe_name_field'),
  controller: _nameController,
  // ...
)

Required on all form input fields (TextFormField, DropdownButtonFormField), interactive buttons (save, cancel, add, remove), and dynamic form sections. Enables reliable E2E test selectors and improves accessibility.
