Issue Creator ⭐

Triggers
"Create an issue for…" "I found a bug…" "Feature request…" User reports problem
Purpose
  • Transform informal reports into structured GitHub issues
  • Interactive 6-checkpoint process for accuracy

  • Detect and reference related issues
  • Generate exact GitHub CLI commands

✦ Guidelines & Success Metrics

Creating a New Skill

1
Use it manually first (3-5 times) — understand pain points before automating
2
Document the workflow — step-by-step process and decision points
3
Design checkpoints — 4-6 logical, verifiable steps with user confirmation
4
Create the prompt using existing skills as templates
5
Test with real issues and refine based on experience

Tips for Success

★
Roadmap → analysis before writing any code
★
UX-heavy issues: mandatory design day first — no code on day 1
★
One test at a time — write, run, verify, then proceed
★
Trust the checkpoints — they prevent rushing
★
30 pts/week cruising; ~20 pts/week on discovery sprints
